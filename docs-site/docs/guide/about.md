# 关于与更新

「设置 → 关于」显示应用信息，也是检查更新的入口。

## 版本与检查更新

顶部卡片显示 App 图标、应用名和一句简介，下面的「版本」行显示当前版本号。

**点版本行手动检查更新**：向本应用的发布服务器查询是否有更新的发布。有新版本时弹窗显示「发现新版本」，正文列出**版本名、安装包大小和完整更新记录**（内容较长时可在弹窗内上下滚动）。正式包（applicationId 为 `com.aicode`）点「下载并安装」可在应用内下载并校验后直接调起系统安装器——首次需要你允许「安装未知应用」，授权后回到 App 再点一次即可，安装包不会重下；fork 自建更新源给出直链时则点「立即更新」交给系统下载器。下载过程中关掉弹窗不会中断，再点一次「版本」行就能回到进度界面。下载失败可点「重试」或改用浏览器去 Release 页面拿包。已经是最新版会提示「已经是最新版本」；网络失败会提示「检查失败」并给出错误信息。

首次检查（全新安装后的第一次）只用来记住当前的发布版本号，**不会弹更新窗**；之后再检测到更新的发布就会提示。注意：如果首次检查时服务器上还没有发布版（也就没东西可记），那么它第一次出现发布版时会**正常提示**，不会被当成“首次”而漏掉。

## 自动检查更新

默认开启。打开 App 进主页时在后台异步检测，**每天最多成功一次**（检测成功后的当天不再重复）。发现新版本会自动弹出更新窗；网络失败时静默处理、不打扰你，也不占用当天那一次——下次启动会再试。

发布服务器在国内时通时不通，检测失败一律当作「没有更新」，不影响 App 的任何其它功能。

关闭开关后不再自动检测，但手动点版本行仍然可以检查。

## 下载镜像源

更新包默认从 `cdn.gh-proxy.com` 这个 GitHub 加速节点下载（`github.com` 直连在国内经常很慢甚至超时）。在同一页点「下载镜像源」可以改：

- **gh-proxy CDN**：默认节点。
- **gh-proxy 优选节点**：同项目的另一个节点，网络环境不同时可能更快。
- **直连 GitHub**：不使用镜像，直接从 `github.com` 下载。
- 也可以自己填任意加速前缀（形如 `https://你的镜像/`），支持 `{url}` 占位符写法。

镜像不可用时 App 会自动改用直连重试一次，所以填错也不会把更新卡死，只是多花一点时间。填完记得点「保存」。

## 其它入口
