# 软件权限

「设置 → 软件权限」集中管理 App 需要的系统级权限。权限状态在页面恢复时（包括从系统设置页返回）自动刷新，已授权的项点击后不会有反应。

后台保活、屏幕常亮、AI 完成通知这三个开关在[后台运行](/guide/background-run)页。

## 安装未知应用

显示当前是否已允许。未允许时点这一行会跳到系统设置里本应用的「安装未知应用」开关页，开启后才能安装 APK。

## 访问存储空间

显示当前是否已授权。未授权时点击会弹系统权限申请框，用于读写工作区文件与容器镜像。

如果权限已被永久拒绝（系统不再弹框），会有弹窗提示，点「去设置」手动开启。

## 忽略电池优化

显示当前是否已豁免。未允许时点击跳到系统的电池优化申请页，对本应用豁免省电策略，降低后台进程被杀的概率。

## 自启动管理

点击跳转到你设备厂商（小米、华为、OPPO、vivo、魅族等）的自启动管理设置页，允许 App 在开机或被系统终止后自动拉起。厂商设置页打不开或匹配不到厂商时，会回退到本应用的详情页。

这一项配合「后台运行保活」和「忽略电池优化」一起使用，能进一步降低后台被终止的概率——国产 ROM 的后台限制比较激进，若长任务经常被打断，建议三项都开启。

## Shizuku 授权

Shizuku 让本应用可以执行系统命令，是 AI 的 `Shizuku` 工具的前提。这一行显示当前状态：

- **未就绪**：点击打开 Shizuku 应用启动服务；设备上没装管理器时，点击会跳到官方下载页。
- **未授权**：点击申请授权，在 Shizuku 弹出的授权框里选「允许」。
- **已就绪**：授权完成，AI 即可调用 `Shizuku` 工具；下面多一行「当前连接」，写明当前是以 adb shell（uid 2000）还是 root（uid 0）身份连上的。

从 Shizuku 应用返回本页时状态会自动刷新。用法与安全注意事项见 [Shizuku 工具](/guide/shizuku)。

## 设备 root 通道

检查设备是否已 root。**Root 工具与虚拟屏功能共用这一个前置条件**：可用则 AI 的 `Root` 工具能以 uid 0 跑系统命令、虚拟屏也能创建；不可用则两者都不可用（与 Shizuku 无关——Shizuku 是另一条通道，以 adb shell 身份执行命令）。

这一行显示当前状态：**未检测**（还没查过）、**检测中…**、**可用**、**不可用**。点这一行会检测一次（本质是跑一次 `su -c id` 看能否拿到 uid 0），结果一直保留到下一次检测。

## 无障碍读屏服务

控制虚拟屏的「控件树观察」能不能用。开启后，AI 可以按虚拟屏读取界面控件（名称、文本、坐标、可点性），比逐张截图省很多 token；不开启时仍可用截图观察，只是慢一些、成本高一些。

这一行显示**已开启 / 未开启**，点击跳到系统的无障碍设置页，请在列表里找到本应用的服务开关打开；从系统设置页返回本页时状态会自动刷新。

该服务是只读的：只导出虚拟屏那一个屏幕的控件信息，不拦截输入、不注入手势，也不会采集密码框里的内容。
