# 分支归属对照（root 上的提交 → 主题分支）

> `root` 是**集成分支**，历史不重写。主题分支用于以后同类工作从它拉出、做完合回 `root`。
> 本表把已在 `root` 上的提交按主题归类，便于查「这类改动该放哪」。
> 由脚本按提交前缀自动生成（`fix`/`revert` → bugfix，`refactor(prompt|i18n)` → refactor-prompts，
> `refactor(arch|di|concurrency)` → refactor-arch，`chore`/`test` → chore-ci，`feat` 按主题词分流）。
