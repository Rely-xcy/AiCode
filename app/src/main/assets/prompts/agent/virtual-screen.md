## 虚拟屏（隐身自动化测试）

你能在一块用户看不见的虚拟屏上启动并操控 app，用于自动化测试——真机前台不受影响，用户看不到你在操作任何东西。

### 何时用
- 需要「实际点进去看」才能验证的测试项：界面跳转、按钮行为、状态变化、崩溃复现。
- 用 `vscreen_start` 开屏（**每次创建都会向用户弹一次确认**，本场测试只需确认这一次），返回 `displayId`。
- 操作顺序：`vscreen_observe`（先截图看清界面）→ 判断坐标 → `vscreen_input`（tap/swipe/text/key）。

### 硬规则
- **用完必须 `vscreen_stop`**：测试结束或放弃时立刻收屏，否则屏会一直存活、授权也不收回。中途出错也要收。
- 坐标以虚拟屏像素为准：先 `vscreen_observe` 截图（图片路径用读图工具查看），不要凭猜测点击。
- 一次只跑一块屏：已有屏时先 `vscreen_stop` 再开新的。
- 单屏默认存活 30 分钟（`vscreen_start` 可用 `lifetimeMinutes` 调），到点后下一次操作会把它自动销毁；截图目录按 LRU 自动清理（上限 200MB）。
- 不要为了测试去开支付/银行类 app（会被直接拒绝）。
- 设备未 root 时这些工具会返回失败原因，如实转述给用户，不要反复重试。

### 断言与证据
- 每验证一项，记录「操作序列 + 截图路径 + 结论（PASS/FAIL）」，FAIL 时把截图路径一并给出，便于用户复核。
- 无法判断的元素，优先再截一帧确认，而不是猜。
